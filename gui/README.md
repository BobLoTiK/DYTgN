# net-suite GUI

Окно поверх того же `netsuite.ps1`: те же компоненты, те же скрипты, только вместо
консольных ярлыков — панель с состоянием и одной кнопкой.

Зачем: у одинаковых по сути сборок (zapret + tg-ws-proxy) есть удобные оболочки, и
пользоваться консолью, когда есть окно, — лишняя работа. Здесь окно своё, поверх
собственного пульта, поэтому ничего не переписывается и не ломается.

## Что внутри

| Страница | Что делает |
|---|---|
| **Пульт** | живое состояние четырёх частей (zapret, TgWsProxy, notion-туннель, PAC) каждые 3 с, кнопки «Включить всё / Перезапустить / Выключить», журнал |
| **Конфиги** | скан всех 20 профилей zapret с рейтингом по живым сайтам и временем отклика, применение выбранного в службу |
| **DNS** | смена DNS одним нажатием (Cloudflare / Google / Yandex / AdGuard / Xbox-DNS / DHCP) и шифрованный DNS (DoH) |
| **Диагностика** | пинг, скорость вниз/вверх через curl, доступность DC1–DC5 Telegram, коды ответов youtube/discord/google/chatgpt напрямую |
| **Настройки** | пути, автозапуск, задача keepalive, `git pull`, пересборка, журналы |

Трей: правый клик — открыть, включить всё, выключить, выход. Крестик сворачивает в трей.

## Сборка

Нужен только .NET Framework 4.8 (он есть в Windows) — ни SDK, ни NuGet, ни установщика.

```powershell
powershell -ExecutionPolicy Bypass -File gui\build.ps1
```

На выходе `gui\NetSuite.exe` (~120 КБ). Собирать надо только если правил `gui\src\*.cs`;
готовый exe лежит в репозитории.

Самопроверка интерфейса без кликов по рабочему столу — приложение снимает все страницы
в PNG и выходит:

```powershell
gui\NetSuite.exe --shot C:\temp\shots
```

## Как оно общается со скриптами

- Состояние (процесс `winws`, порт 1443, socks 10808, PAC 10810, коды сайтов, notion через
  SOCKS) GUI проверяет сам, без вызова PowerShell — иначе обновление раз в 3 секунды
  стоило бы секунды на каждый запуск.
- Действия `on/off/status/auto/restart` — это `netsuite.ps1`, его вывод построчно падает
  в журнал окна.
- Права администратора: GUI запускает **сам себя** с `--elevated <задача> <in.json> <out.json>`
  через UAC. Привилегированная половина делает дело и пишет ответ в json, окно читает.
  Поэтому кода с `Start-Process -Verb RunAs` в скриптах не прибавилось.
- Пути и порты берутся из `netsuite.json` — один конфиг на окно и скрипты.

## Скан профилей

`gui` вызывает `zapret\scan.ps1` (новый, рядом с `pick.ps1`):

```
powershell -ExecutionPolicy Bypass -File zapret\scan.ps1                         # перебрать всё
powershell -ExecutionPolicy Bypass -File zapret\scan.ps1 -SettleSeconds 3        # быстрее
powershell -ExecutionPolicy Bypass -File zapret\scan.ps1 -Apply "general (ALT4).bat"
```

Скрипт гасит `winws`, по одному запускает профили, читает фактическую командную строку
`winws.exe`, проверяет YouTube/Discord, пишет рейтинг в `logs\scan-results.json`
(и прогресс в `logs\scan-progress.json`, из него окно рисует полосу), а в конце
возвращает службу `zapret` в то состояние, в котором она была. `-Apply` вписывает
выбранный профиль в службу и проверяет результат.

Требует администратора. Один прогон — около двух минут (20 профилей × 5 с), на это время
обход DPI выключается.

## Журналы

`logs\gui-YYYYMMDD.log` — всё, что окно писало и что отвечали скрипты.
`logs\zapret-scan.log` — скан профилей.

## Ограничения

- Самообновления нет: обновление — `git pull` + пересборка (обе кнопки в «Настройках»).
- Модов под игры и редактора листов доменов нет (в отличие от NetFix) — сознательно:
  списки править удобнее в `lists\` текстовым редактором.
- DoH: регистрируется через `netsh dns add encryption`. Видно ли шифрование в
  «Параметрах → Сеть → DNS» — зависит от сборки Windows.
- Окно не умеет работать без `netsuite.json` рядом: это не самостоятельная программа,
  а пульт над репозиторием.
